# Contributing

1. **Create a branch** for your change: `git switch -c short-description`
2. **Commit** small, focused changes with clear messages.
3. **Push** and open a **pull request** against `main`.
4. Check the **Cloudflare preview link** on the pull request.
5. Get at least one review, then **merge**. The site updates automatically.

Nobody pushes directly to `main`; it is protected in the GitHub settings.

## Don't commit

- Passwords, API keys or other secrets
- Anything that shouldn't be public: this repository may be public
